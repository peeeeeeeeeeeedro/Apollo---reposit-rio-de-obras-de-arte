# 🎨 Acervo de Obras de Arte

## 📖 Sobre o projeto

O **Acervo de Obras de Arte** é um site desenvolvido com o objetivo de reunir e apresentar diferentes manifestações artísticas em um único espaço digital.

O projeto funciona como um acervo virtual, no qual os usuários podem explorar obras de diferentes categorias, como **pintura, cinema e música**, conhecendo diferentes artistas e produções.

Além de consultar as obras disponíveis, o usuário também pode **avaliar suas obras favoritas utilizando um sistema de classificação por estrelas**, tornando a experiência mais interativa e permitindo registrar suas preferências.

---

## ✨ Funcionalidades

* 🖼️ Visualização de obras de arte;
* 🎨 Organização das obras por categorias;
* ⭐ Sistema de avaliação por estrelas;
* 🔎 Navegação pelo acervo;
* 💻 Interface desenvolvida para proporcionar uma experiência simples e intuitiva.

## 🛠️ Tecnologias utilizadas

O desenvolvimento do projeto utiliza as seguintes tecnologias e ferramentas:

### Linguagens

* **HTML5** — estruturação das páginas;
* **CSS3** — estilização e organização visual da interface;
* **JavaScript** — implementação da interatividade e funcionalidades do site.

### Ferramentas

* **Visual Studio Code** — ambiente utilizado para desenvolvimento e edição do código;
* **XAMPP** — utilizado para disponibilizar um ambiente de servidor local;
* **Node.js** — utilizado como ambiente de execução para JavaScript e suporte ao desenvolvimento do projeto.

### 1. Clone o repositório

```bash

```

### 2. Acesse a pasta do projeto

```bash
cd seu-repositorio
```

### 3. Abra o projeto

Abra a pasta do projeto no **Visual Studio Code**.

Caso o projeto utilize o **XAMPP**, coloque os arquivos na pasta correspondente ao servidor local, normalmente:

### 4. Acesse o site

No navegador, acesse:

```text
http://localhost/seu-repositorio/
```

## ⭐ Sistema de avaliação

Uma das principais funcionalidades do projeto é o sistema de avaliação das obras.

O usuário pode selecionar uma quantidade de **estrelas de 1 a 5**, indicando o quanto gostou de determinada obra.

Exemplo:

```text
★☆☆☆☆  →  1 estrela
★★☆☆☆  →  2 estrelas
★★★☆☆  →  3 estrelas
★★★★☆  →  4 estrelas
★★★★★  →  5 estrelas
```

Esse recurso tem como objetivo tornar o acervo mais interativo e possibilitar que os usuários expressem suas preferências.
